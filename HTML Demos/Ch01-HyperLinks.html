Note that we use / even on a Windows machine (which uses \ for files). This is because the notation comes from Unix, the OS on which Web servers were first imolemented.

Relative notations don't work reliably at all if you are accessing your pages with the file: protocol in the URL since the browser can't work out where the root folder is. In truth, please always develop your web pages on a web server. To work around this and you insist on using the file: protocol, you must put the full path (from the root of the drive) into every link
